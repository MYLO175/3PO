# Review and plan a week

Follow the [3PO operating contract](../../references/3po-contract.md).

Resolve the week and timezone, reading only its bounded Calendar range and relevant task/project branches. Load applicable planning guidance and maintained project context with its working changes.

For a progress review, include relevant completed local tasks as well as unfinished work. Distinguish recorded completion from inferred progress, elapsed deadlines and calendar attendance. Do not assume an external application or report was submitted because a task date passed.

Identify the meaningful outcomes, fixed commitments, upcoming deadlines, capacity and dependencies. Use incomplete Reminders where they belong in the requested scope. Ask about priorities only if the saved context and current request leave a material choice unresolved.

Return a realistic set of priorities and a sequence across the week, with evidence/freshness limits. Make proposed moves and work blocks visibly different from existing events.

Weekly planning does not create an automation or begin future monitoring. Save project/calendar/reminder changes only when requested or accepted in this conversation, using their actual tools and separate verified outcomes.
