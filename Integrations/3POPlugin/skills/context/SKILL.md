# Work with context

Follow the [3PO operating contract](../../references/3po-contract.md).

Use about_3po's information map to select a relevant project/topic page. Read read_context_page with its parent/child index, support and working changes. Follow pagination only for pages needed to answer the request.

For a project's actual current structure or work state, also use read_life_items. For a supporting fact, use read_memory/read_life_notebook. State when a maintained summary is older than a current source or cannot establish the requested detail.

For human context notes, use read_context_notes to get the correct owner and revision. Use change_context_note only for the requested create, edit or forget operation, preserving unrelated notes.

Maintained/generated pages are read-only. Correct their underlying human fact, note or instruction as requested; do not overwrite the generated summary or promise immediate heartbeat regeneration.

Explain the relevant background and where it came from. For a note change, confirm the specific saved result. Distinguish forgetting that note and its history from deleting separate evidence or conversations.
