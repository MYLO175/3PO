# Start with 3PO

Follow the [3PO operating contract](../../references/3po-contract.md).

Call about_3po on first use. Read the current Assistant instructions. Explain that 3PO holds Calendar, Reminders, nested Projects, saved Review, memory and instructions, and that the current assistant supplies the reasoning and reply.

If there is a concrete task, continue with the relevant tools and applicable feature instructions. Do not turn setup into a questionnaire or read every source to build a profile. If the user only selected the plugin, give a short introduction and a few useful starting points.

A successful orientation call confirms an app connection; a skill appearing in a picker does not. When unavailable, explain the actual running-app/source-context/External assistants prerequisites. Do not edit client configuration, restart another app or perform a disposable write merely to prove setup.

The desktop plugin needs the running Mac app. State surface limits honestly: a local plugin connection is not automatically a web connector. Keep existing connections usable until a replacement is verified.

Return a short connection/capability result and the requested useful answer or next essential setup step. Do not include the private discovery token or personal data in setup diagnostics.
